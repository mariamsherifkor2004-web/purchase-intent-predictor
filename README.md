# Will This Visitor Buy? – Purchase Intent Predictor

#Project Overview
A machine learning project that predicts whether an online shopping visitor is likely to complete a purchase based on their browsing behavior and session information.

## Problem Statement
The goal is to help e-commerce businesses identify visitors with a high purchase intention and make better marketing and conversion decisions.

## Dataset
The project uses the Online Shoppers Purchasing Intention Dataset from the UCI Machine Learning Repository.

Dataset source: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

- Data exploration and visualization
- Data preprocessing and feature engineering
- Baseline model and multiple machine learning algorithms

## How to Run Locally

1. Clone this repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`
